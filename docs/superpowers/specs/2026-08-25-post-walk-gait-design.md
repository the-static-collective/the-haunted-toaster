# Post-WALK Gait Design

**Date:** 2026-08-25  
**Status:** Human-approved design; implementation not yet authorized  
**Branch:** `design/post-walk-gait`  
**Primary implementation frontier:** #242 — POST-WALK AXIS GRAMMAR  
**Sequenced descendants:** #250 Video Digestion vNext → MADDCL0WN crucible → human-hands work (#181 / #207)

## Purpose

The Haunted Toaster has completed the WALK machine proof and a real human field witness. The next problem is not giving it more organs. The next problem is teaching the organs it already has to coordinate into a repeatable gait.

The design decision is:

```text
A — CONJUGATE EXISTING ORGANS
        ↓
B — DIGEST FOREIGN MATERIAL
        ↓
MADDCL0WN — ADVERSARIAL CRUCIBLE
        ↓
C — GIVE THE HUMAN BETTER HANDS
```

Compression:

> **Do not add another effect. Make the existing organs conjugate.**

This document defines the sequence and the boundaries between those stages. Only **Stage A** is the next implementation slice. B, MADDCL0WN, and C are explicitly downstream and require their own implementation decisions after A has been witnessed.

## Current witnessed truth

The design starts from the narrowest claims the current evidence supports.

From WALK E / Windows Witness #2:

- the machine composition and retained authority/genealogy seams are green on the exact WALK package lineage;
- GRAB was visibly legible in a real render;
- admitted Video was used as compositional material rather than reading as a stock-video cutaway;
- the aggregate result read as compositionally intentional;
- SPEAK and APERTURE were active but remain perceptually under-characterized by eye;
- the witness does not manufacture individual GROW, BODY, or KITCHEN SINK verdicts that were not observed;
- successful Video assimilation opens a separate digestion frontier rather than widening WALK E.

Therefore:

1. WALK evidence remains WALK evidence.
2. Post-WALK work begins from existing lawful mechanisms.
3. Human perceptual fog is calibration evidence, not permission to rewrite machine history.
4. New creative range should come from composition among proven mechanisms before new effect families are introduced.

## Governing laws

### 1. Authority stays upstream of rendering

```text
source / admitted evidence
  → Lane Bank / Creative Context
  → candidate recipe / Mix Plan proposal
  → human acceptance
  → accepted VisualScore / ResolvedTimeline / accepted plan evidence
  → shared preview + final render
```

The renderer may execute accepted semantics. It may not invent missing stance, scope, consequence, shape, routing, or authority.

### 2. Proposal is not authority

Evidence availability does not imply consumption. A generated candidate does not become executable merely because it exists. Locks, refusals, acceptance, lineage, and retained receipts remain explicit.

### 3. Same semantics, same replay

The same frozen inputs, policy, locks, and seed must reproduce the same candidates, accepted plan semantics, timeline, and receipts. Preview and final render consume the same accepted meaning.

### 4. Historical meaning does not silently upgrade

Artifacts created before the post-WALK grammar do not acquire new axis semantics unless an explicit versioned migration says so.

### 5. Creature surface over knob wall

The grammar belongs beneath the six-up creature proposals and inside inspectable receipts. The ordinary product posture remains closer to:

```text
six creatures
    ↓
pick
    ↓
KEEP TOAST | SCRAPE TOAST
```

than to a conventional panel of permanent effect controls.

# Stage A — Conjugate Existing Organs

**Issue:** #242  
**Status:** next implementation frontier after this spec is reviewed and an implementation plan is approved.

## Goal

Prove that the Toaster can take one admitted evidence set and lawfully produce materially different creatures by composing three already-latent dimensions:

```text
RESPONSE STANCE × SCOPE × CONSEQUENCE
```

No new renderer subsystem should be required to pass the proof.

## Axis 1 — Response Stance

Minimum vocabulary:

- `follow`
- `oppose`
- `accent`

The same evidence lane must be able to produce materially different relations without changing source truth.

`oppose` must not collapse into trivial amplitude inversion or a renamed equalizer visualization. It must be relationally distinct in the accepted plan.

## Axis 2 — Scope

Minimum vocabulary:

- whole lawful destination / layer;
- bounded GRAB-local region.

A local act must remain local. There is no hidden whole-frame fallback when bounded scope cannot be satisfied. Illegal or unavailable scope refuses.

## Axis 3 — Consequence

Use only consequences already supported by current lawful mechanisms. The founding proof needs at least two mechanically and visibly distinct outcomes, selected from concepts such as:

- clean return / recoil;
- residue / scar;
- persistent displacement or existing GROW ancestry where current accepted semantics support it.

The causal question is:

> **After the act, did the world return, or did something remain?**

## Six-up proof family

From one frozen source and one fixed admitted evidence set, generate six deterministic candidates with deliberate orthogonal coverage before randomness.

The exact recipes are implementation choices, but the family should span combinations analogous to:

1. FOLLOW × whole × clean return
2. OPPOSE × whole × scar
3. ACCENT × GRAB-local × recoil
4. FOLLOW × GRAB-local × residue
5. OPPOSE × GRAB-local × persistent consequence where lawful
6. integration-stress combination selected from the same existing organs

The invariant is not these exact six rows. The invariant is:

```text
orthogonal coverage
+ legality
+ deterministic replay
+ materially distinct accepted semantics
```

## Representation boundary

Stage A should introduce or refine one versioned recipe / Mix Plan representation capable of naming the three axes without creating three isolated renderer systems.

A useful conceptual shape is:

```text
WHAT DID IT HEAR?
        ↓
WHAT STANCE DID IT TAKE?
        ↓
WHERE DID IT ACT?
        ↓
WHAT REMAINED AFTERWARD?
```

The representation should adapt existing #208 Render Mutation Grammar and #225 Mix Plan semantics rather than superseding them.

## Refusal behavior

Stage A must fail closed when a combination cannot be executed lawfully.

Examples:

- requested local scope has no lawful region;
- consequence cannot be supported by the current accepted plan;
- one axis conflicts with an absolute lock;
- genealogy or accepted authority no longer matches the proposed execution;
- replay cannot reconstruct the same accepted semantics.

There is no silent coercion to a default combination.

## Stage A negative controls

The proof fails if any of the following occur:

- `oppose` is only inverted gain;
- GRAB-local behavior leaks into the whole frame;
- consequence names differ while the post-event state does not;
- six-up variation is mostly intensity while receipts claim orthogonal diversity;
- selecting one axis secretly selects another, e.g. GRAB always means scar;
- the renderer manufactures a missing axis choice;
- an illegal combination silently downgrades;
- a new monolithic effect preset is introduced to make the demonstration easy;
- existing ordinary six-up behavior changes meaning when the new grammar is absent.

If two proposed axes prove mechanically inseparable, the correct result is to collapse or redefine the abstraction, not preserve a pretty model that the machine does not support.

## Stage A acceptance gate

A is complete only when all of the following are true:

1. One versioned recipe / plan representation can name Response Stance, Scope, and Consequence.
2. One fixed evidence set yields deterministic candidates with materially different combinations across the three axes.
3. At least one `oppose` result is demonstrably relational rather than equalizer-like.
4. At least one bounded-scope act proves no leakage outside its accepted region.
5. At least two consequence outcomes remain mechanically and perceptually distinct after the event.
6. Locks and refusals remain explicit and absolute.
7. Replay reconstructs evidence → recipe / Mix Plan → accepted execution semantics → receipt.
8. Preview and final render preserve semantic parity.
9. Historical artifacts and ordinary six-up behavior retain their prior meaning when the axis grammar is absent.
10. The proof creates a clean descendant seam for aperture-shape expansion without requiring that expansion to pass A.

### A stop condition

Stop when the Toaster can truthfully demonstrate:

> **The same thing can matter to two creatures in different ways, in different places, and leave different lawful consequences — using machinery we already had.**

Do not keep expanding A after that proof survives.

# Stage B — Digest Foreign Material

**Issue:** #250  
**Status:** sequenced after A; not part of the first implementation plan.

## Goal

Once the general grammar exists, prove that admitted moving material enters that grammar as food rather than becoming a special video-editing subsystem.

The first bounded experiment should use the same admitted clip in at least two deterministic descendants, for example:

- the current clip-luma / texture treatment;
- one topology-oriented treatment using the same source ancestry.

Both descendants must preserve:

- common admitted source ancestry;
- distinct accepted plan identities;
- deterministic replay;
- preview/final parity;
- no new authority granted merely because the material is Video.

The governing principle is:

> **The clip becomes food, not footage.**

B should consume A's grammar where it fits rather than inventing a parallel grammar for Video.

# MADDCL0WN — Adversarial Gait Crucible

**Status:** conceptual gate between B and C; no product behavior of its own.

## Purpose

Before the human interaction layer hardens the new semantics into familiar gestures, run the post-WALK grammar through an adversarial discriminator pass.

MADDCL0WN is not another creative organ. It is a hostile witness whose job is to find places where the architecture only appears lawful under friendly examples.

## Attack classes

At minimum, the crucible should attempt to expose:

- axis coupling disguised as independence;
- local-scope leakage;
- renderer-invented defaults;
- consequence labels without persistent mechanical distinction;
- replay drift;
- receipt / execution authority mismatch;
- Video-only special cases masquerading as general grammar;
- candidate genealogy loss across mutation or failure;
- visually distinct results produced by semantically identical receipts;
- semantically distinct receipts that collapse to the same execution;
- interaction pressure that would force a giant knob wall to make the system understandable.

## Verdict vocabulary

The crucible should produce a bounded architectural verdict such as:

- **PROMOTE** — distinction survives and may become trusted product grammar;
- **SPLIT-REQUIRED** — current abstraction hides more than one mechanism and must be separated;
- **COLLAPSE** — proposed axes are not meaningfully independent;
- **REFUSE** — proof cannot support the claimed behavior without violating authority or provenance.

The crucible does not repair evidence by inventing it.

# Stage C — Give the Human Better Hands

**Related work:** #181 / #207 and the existing Listener / KEEP TOAST / SCRAPE TOAST direction  
**Status:** downstream of A, B, and MADDCL0WN.

## Goal

Expose a small human interaction surface only after the semantics beneath it have survived real composition and hostile review.

The likely product posture is:

```text
LISTEN
  ↓
SIX CREATURES
  ↓
PICK
  ↓
KEEP TOAST | SCRAPE TOAST
  ↓
RE-LISTEN / MUTATE / CONTINUE
```

The human should manipulate proposals and trust decisions, not manually operate every internal dial.

C must not freeze unresolved metaphors prematurely. If SPEAK or APERTURE remain perceptually foggy, the UI should not pretend the human already has a stable visual language for them.

# Sequence gates

The intended developmental sequence is:

```text
WALK
  ↓
A — CONJUGATE
  ↓
A HUMAN WITNESS
  ↓
B — DIGEST
  ↓
B HUMAN WITNESS
  ↓
MADDCL0WN
  ↓
C — HUMAN HANDS
  ↓
REMEMBER / WITNESS
  ↓
DREAM
```

A later stage may feed corrections back into an earlier abstraction, but it must not silently rewrite the earlier witness record.

## Why MADDCL0WN belongs between B and C

A proves the grammar on general existing organs. B tests whether foreign moving material can participate without becoming exceptional. At that point the system has enough real range to justify a hostile architecture pass.

Running MADDCL0WN before C prevents the interface from teaching humans a metaphor that later turns out to be mechanically false.

# Non-goals

This design does not authorize:

- reopening or widening WALK E;
- merging PR #249 or any WALK branch without its own landing decision;
- adding a new effect family merely to demonstrate axis coverage;
- building a conventional video editor;
- exposing every internal dimension as a UI control;
- memory, HAUNT, or DREAM behavior before the corresponding ancestry is trustworthy;
- manufacturing perceptual verdicts for SPEAK, APERTURE, GROW, BODY, or TEST 6 cases not actually witnessed;
- implementing B, MADDCL0WN, and C in the same code slice as A.

# Testing strategy

Stage A implementation should be test-first and preserve existing repository proof habits.

The eventual implementation plan should identify exact files after reading the current integration target, but the required proof classes are already known:

- deterministic candidate-family tests;
- axis representation / serialization tests;
- lock precedence tests;
- explicit refusal tests;
- bounded-scope leakage tests;
- consequence persistence tests;
- genealogy / accepted-authority parity tests;
- replay tests;
- preview/final accepted-semantics parity tests;
- historical / grammar-absent compatibility tests;
- at least one real production render witness after machine gates are green.

Machine proof and human witness remain separate receipts.

# Implementation boundary after spec approval

The next implementation plan must cover **Stage A only**.

B, MADDCL0WN, and C remain durable sequencing constraints and future design inputs. They do not enlarge the first code change.

That keeps the gait developmental rather than sprawling:

```text
learn one lawful step
→ witness it
→ feed it stranger food
→ attack the abstraction
→ only then improve the hands
```
