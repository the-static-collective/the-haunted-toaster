# Haunted Toaster BETA Creative Freedom — Field Design

**Status:** field-backed design checkpoint, 2026-08-18

**Parent:** #148 — Living Creative Playground

**Trusted integration candidate:** PR #175 — `beta/spine-integration`

## Governing product law

The BETA goal is not to add a larger human control panel. It is to give the Toaster more lawful degrees of freedom so it can make more kinds of decisions while preserving the authority, replay, receipt, and witness boundaries that made the current renderer trustworthy.

> **Keep the Toaster's personality. Increase its expressive vocabulary.**

The human should bias the weather and recognize interesting creatures. The machine should compose.

A successful expansion therefore means:

- more materially different initial candidates;
- more internal ways for an accepted creature to move, deform, change, haunt, scar, reveal, and recover;
- more lawful combinations of existing primitives before inventing new axes;
- no silent renderer improvisation;
- no requirement that “more freedom” mean louder, brighter, faster, or more extreme;
- no wall of fine-grained user knobs.

## Creative-freedom expansion law

The next work should increase the number of things the Toaster can lawfully decide, not increase the number of things the human must specify.

Good freedom:

- stronger candidate-family diversity;
- richer topology anatomy;
- more expressive but bounded topology-response temperaments;
- bolder lawful apparition/scar/possession interactions;
- atmosphere acting as participant rather than decorative overlay;
- stronger initial chromatic diversity;
- source-image clarity becoming reachable without becoming preferred;
- later, deterministic consumption of Video/VSPantry material.

Bad freedom:

- renderer-local randomness;
- hidden nondeterministic state;
- extra sliders for every compiler parameter;
- automatic “make it crazier” amplitude inflation;
- direct background-video playback pretending to be assimilation;
- broad rewrites of the accepted `VisualScore → ResolvedTimeline → render → receipt` boundary.

## Executable slices

These are separate implementation slices. They should not be bundled into one creative-expansion PR.

### Slice 1 — #147 candidate ecology first

Keep #147 as the first behavior expansion after the integration ancestor is admitted.

It owns:

- fresh ordinary six-up without mandatory Toast Feel preselection;
- Toastmoods as latent family-composition pressures;
- no privileged initial candidate;
- exactly two-parent CROSS;
- typed, inspectable inheritance;
- deterministic genealogy;
- coverage before randomness.

#### New field requirement: chromatic starting-state coverage

Current Mutation Lattice selection strongly rewards topology/base identity/structure/dynamics. Field testing shows the first six can still arrive chromatically too close together, especially around Linear.

Promote starting chromatic identity into meaningful family-distance evidence without creating a quota such as “one palette per card.” Useful evidence includes:

- initial `palette.logic`;
- native-color relationship;
- contrast/bleed regime;
- topology × chromatic pairing.

Invariant:

> Six different skeletons wearing the same chromatic neighborhood are not yet a maximally useful first six-up.

Do not let chromatic coverage override locks, constraints, or stronger lawful diversity evidence.

### Slice 2 — Linear v3 as a real topology family

Current raster-4 still registers Linear as `linear-v1` with no dedicated topology compiler. Other raster-4 topologies have actual geometry compilers.

Do not add a new canonical axis. Let Linear consume already-authoritative primitive structure and dynamics more deeply.

Candidate mapping for design/proof:

- `scope` → classic linear witness;
- `ribs` → multi-rail / parallel linear anatomy;
- `lattice` → cross-stitched or intersecting line field;
- `branches` → branching/splitting linear organism;
- `facets` → angular segmented planes;
- `folds` → mirrored/broken hinge behavior;
- `torus` → return-path / bent-loop linear behavior where geometrically lawful.

Historical policies stay pinned. `linear-v3` belongs only to the raster-4/BETA renderer policy.

Acceptance is perceptual as well as mechanical: multiple Linear candidates should no longer collapse into the same perpendicular pose when their accepted primitive structures differ.

### Slice 3 — VSPantry intake observability

Do not rewrite a working catalog path merely because the current batch feels dead.

First bounded improvement:

- visible current-file progress;
- completed / admitted / duplicate / refused counts during the run;
- final explicit summary;
- cancellation/refusal remains safe;
- no change to specimen identity or catalog authority.

Recursive traversal may be added only if real source folders demonstrate that nested layout is a practical need; it is not required to prove the progress repair.

### Slice 4 — Listener accuracy mining

Use #113 rather than creating a second Listener authority.

Collect several packaged runs and compare:

- short-line failure rate;
- repeated-section / wrong-chorus placement;
- first-pass placement count;
- human correction count;
- unresolved count;
- behavior after explicit Re-listen with human anchors.

Do not tune from one song. Human anchors remain authority; confidence remains evidence.

### Slice 5 — Video assimilation after ecology is stable

Issue #44 remains the implementation authority.

The first useful step is not “play the video behind the topology.” It is one deterministic assimilation operator that converts an admitted specimen into Haunted Toaster material while preserving preview/production parity and receipt evidence.

Frame Reservoir is already the safe still-addressing foundation. Full Frame Motion execution remains deferred until one bounded operator proves itself.

## Stop condition for the creative-freedom program

Do not stop when the Toaster has more parameters.

Stop when repeated field sessions demonstrate that it can make materially more kinds of lawful decisions while remaining recognizably itself:

> **more ways to surprise without ceasing to be the Toaster**

and every accepted world remains reproducible from recorded authority.
