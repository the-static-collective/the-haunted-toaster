# Haunted Toaster alpha.8 — Creative Expansion Design

**Status:** approved design; executable implementation plans written  
**Target:** `0.5.0-alpha.8`  
**Base at design approval:** `main` at `56e006123f0231ac3a92f71762d25eeae15fc19a`  
**Known-good ancestor:** `archive/gold-star-renderer-alpha7`

## Product thesis

alpha.7 proved that the Haunted Toaster can already produce strong, coherent, song-responsive visual work. alpha.8 should therefore stop asking the existing renderer to prove itself again.

> **Same proven creature. New way to summon it. New relationship to the source image. Better proof that the appliance actually contains what we built.**

The release is deliberately narrower than the full research backlog. Its center is:

1. preserve future native render-failure evidence without requiring reproduction of the historical crash;
2. make the real renderer UI witnessable at the commit/PR boundary;
3. replace the narrow Starting Field furniture with Seven Toast Feels;
4. add a bounded first Native Color Witness / Chromatic Decompression mechanic;
5. preserve the distinction between creative choice and downstream transport;
6. package and witness the resulting Windows appliance as `0.5.0-alpha.8`.

## Release law

alpha.8 is not a renderer rewrite.

```text
source evidence
  -> candidate generation / accepted VisualScore
  -> ResolvedTimeline
  -> shared preview + production compiler
  -> Witness Window
  -> transport encoding
  -> receipt
```

New alpha.8 features enter through recorded, versioned inputs or derived plans upstream of execution. No renderer-local improvisation, ambient randomness, preview-only semantics, or hidden UI authority may be introduced.

## Preserved ancestor

The Gold Star alpha.7 renderer remains the route back to known-good behavior. Preserve current six-up diversity, STOMP/outer-rail machinery, Possession Arc, Color Drift, Primitive Field, Atmosphere, Witness Window, deterministic typography, lyric resonance, and old accepted VisualScore/ResolvedTimeline meaning under pinned renderer policy.

## Slice 0 — Failure evidence becomes insurance, not a release hostage

The historical Windows FFmpeg `0xC0000005` specimen is no longer required to reproduce before alpha.8 can move forward.

Issue #116 remains valid diagnostic history. PR #119 is the intended evidence floor: an abnormal score-driven FFmpeg exit preserves a compact sibling bundle with accepted score/timeline, filter graph, arguments, full stderr, build/source/compiler identities, and last render progress.

> **Preserve the failed performance before trying to teach it not to fail.**

No candidate ban, random retry, speculative swscale workaround, or renderer simplification belongs in alpha.8 without a newly preserved specimen proving the seam.

Lack of reproduction of the historical candidate is not an alpha.8 release blocker. A newly reproduced crash on alpha.8 candidate code is ordinary release evidence and must be triaged from the preserved bundle.

## Slice 1 — UI Witness Gate

Before alpha.8 changes the largest visible product surface, interface appearance becomes build evidence.

Issue #122 / PR #124 define the prerequisite. The browser witness renders the actual production renderer assets with a deterministic fake `window.fullMeasure` bridge. It is a witness surface, not a web edition of the Toaster.

Canonical states remain small: empty, song-ready, Toast Feel selected, six-up, Listener, rendering, complete, failure/refusal. Animation/time are frozen for screenshot comparison.

Vercel publishes this disposable witness from production renderer assets. Vercel owns no generation semantics or local appliance authority.

For UI-sensitive changes record:

```text
UI impact: none | behavioral | visual | bridge
browser witness: PASS/FAIL @ commit
visual delta: expected | none | unexplained
packaged witness required: yes | no
packaged witness: PASS/FAIL/not-required
GitBook ontology changed: yes | no
```

## Slice 2 — Seven Toast Feels / Toastmoods

Retire Porchlight / Wire Orchard / Absolute Residual as the primary normal starting furniture while preserving them as ancestry and compatibility.

The normal entry surface becomes six ordinary burnt-toast mood choices plus one conspicuously larger **MADD CLOWN CRAZY SLOTS** choice.

> **Toast Feel biases the creature. It does not dictate the creature.**

A Toast Feel is not a replacement preset. It applies deterministic bounded pressure across existing lawful creative axes; six-up still discovers the actual creature. MADD CLOWN means maximum lawful surprise through the existing STOMP/outer-rail system, not uncontrolled randomness.

Before visual cutover, application identity must be decoupled from DOM furniture. One stable versioned domain manifest is shared through the Electron sandbox boundary; UI, candidate generation, slate, accepted execution, receipt, and tests all use the same identity/version.

The chosen Toast Feel survives:

```text
UI selection
  -> six-up generation
  -> mutation / locks
  -> accepted score/timeline
  -> final render
  -> receipt
```

## Slice 3 — Native Color Witness / Chromatic Decompression v1

The source image becomes a chromatic witness, not merely material to overwrite.

> **The photo is a witness, not just fuel.**

> **Stylization may compress the source, but it should sometimes decompress and let the source testify again.**

alpha.8 v1 is intentionally small:

```text
source image bytes
  -> deterministic NativeChromaticProfile
  -> source-relative ChromaticRelationshipPlan
  -> existing section-relative Color Drift
  -> bounded Native Color decompression window
  -> shared preview + production compiler
```

The profile uses defensible deterministic low-level image statistics. No semantic object/face/region detection is required.

Exactly two relationship classes exist in alpha.8:

- `echo` — remain near / extend the native chromatic field;
- `counterpoint` — deliberately offset or oppose it under bounded deterministic policy.

Additional classes, including chromatic drain/residue, remain outside alpha.8.

At least one lawful recorded temporal event on a suitable multi-section specimen visibly moves treatment back toward source chroma. Native color is an event, not permanent realism.

Toast Feel may bias which relationship is preferred and how far treatment travels, but it never dictates an exact palette or reveal schedule.

Composition order is explicit:

```text
NativeChromaticProfile
  -> source-relative relationship baseline
  -> existing Color Drift modulation
  -> decompression/native return
```

Old/non-expressive timelines remain unchanged.

## Slice 4 — Render/output choice remains transport, not creativity

The normal product keeps the bounded transport distinction:

- **Universal — H.264** (`delivery`) as default;
- **Efficient — HEVC (experimental)** (`efficient`) as optional.

These carry the same accepted visual semantics differently.

```text
accepted timeline
  -> inner visual cadence
  -> presentation frames
  -> Witness Window
  -> H.264 or HEVC transport
```

Do not expose every topology/motion/palette/material/camera/temporal parameter as a conventional front-panel form. Those remain the space explored by Toast Feel, six-up, locks, mutation, and admitted scores.

---

## Listener boundary for alpha.8

Keep already-landed Listener parity/hardening and human-anchor authority. Do not make alpha.8 depend on wrong-chorus structural priors, full song-structure modeling, vocal-biased second pass, Compression Pressure, Witness Session expansion, or broad threshold retuning from insufficient evidence.

## Acceptance witness

alpha.8 is ready to package only when one coherent end-to-end specimen proves:

```text
Gold Star ancestor remains recoverable
  -> failure-evidence floor exists
  -> browser UI witness passes
  -> Toast Feel selection is visible and deterministic
  -> selected Toast Feel lawfully influences six-up
  -> accepted candidate carries Toast Feel identity/version
  -> NativeChromaticProfile is stable for identical source bytes
  -> echo and counterpoint are materially distinct on the same source
  -> at least one deterministic native-color return event is visible
  -> preview and final render agree
  -> Universal H.264 render succeeds
  -> receipt records mood/color/transport evidence
  -> Windows packaged appliance matches accepted interface/evidence boundary
  -> manifest + lockfile become 0.5.0-alpha.8
  -> exact proven main commit receives v0.5.0-alpha.8
```

Regression guards: six-up remains meaningfully diverse; old accepted artifacts retain pinned replay meaning; no ambient randomness; no renderer-local image analysis; no Toast Feel hidden preset branch; no preview-only Native Color; transport never changes creativity; no historical crash workaround without evidence.
