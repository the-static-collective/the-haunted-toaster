
# NEXTGEN-TOASTER-013W — WEIRDNESS COMPILER

Status: experimental descendant of NEXTGEN-TOASTER-012 real pixel resume.

## Thesis

Strangeness is not randomness.

Strangeness is selectively relaxing a relation that the current world normally assumes is fixed.

The first compiler therefore does not implement a psychedelic preset or one global weirdness scalar.

It accepts named orthogonal reality assumptions and compiles explicit relaxations into a derived PerformanceProgram.

~~~
sealed performance
      ↓
PerformanceProgramV0
      ↓
WeirdnessCompilerV0
      ├─ coordinate agreement
      ├─ experienced-time agreement
      └─ history-decay agreement
      ↓
derived PerformanceProgramV0
      ↓
same deterministic pixel executor
      ↓
real pixel consequence
~~~

The original program is never mutated.

## Axis 1 — coordinate agreement

Normal assumption:

~~~
performed position = projected position
~~~

Relaxation:

~~~
PERFORMED SPACE != PROJECTED SPACE
~~~

V0 rotates the projected coordinate field around frame center by a bounded angle proportional to relaxation amount.

The original performance placements remain preserved in the source PerformanceProgram.

The derived program changes only projected action transforms and their transform keyframes.

At amount 0:

~~~
angle = 0°
~~~

At amount 1:

~~~
angle = 90°
~~~

This is not random displacement.

It is a different explicit coordinate relation.

## Axis 2 — experienced-time agreement

The common audio/frame address remains untouched.

~~~
AUDIO CLOCK = COMMON ADDRESS
~~~

But an action may experience its internal time differently:

~~~
EXPERIENCED CLOCK != AUDIO CLOCK
~~~

V0 uses one explicit map:

~~~
normalized experienced time = normalized audio time ^ exponent
exponent = 1 + 3 × amount
~~~

The action start frame, end frame, and duration do not change.

Only the internal clock used for transform interpolation and source-frame progression changes.

At amount 0:

~~~
experienced time = audio time
~~~

At high relaxation:

~~~
early internal motion slows
late internal motion rushes
~~~

The witness raster consumes the compiled time map directly.

The renderer does not invent it.

## Axis 3 — history-decay agreement

Normal assumption:

~~~
the historical scar decays at its inherited rate
~~~

Relaxation:

~~~
HISTORY PERSISTENCE != HISTORY AUTHORITY
~~~

V0 recompiles ResidueMemory from the exact same PerformanceTrace while reducing the explicit linear decay rate.

~~~
new decay =
old decay × (1 - 0.95 × amount)
~~~

At maximum relaxation the scar decays at 5% of its inherited rate.

Its ancestry does not change.

No path-length, velocity, listening, or kinship heuristic is silently introduced.

## Pixel pressure test

NEXTGEN-TOASTER-012 gave the stack exact real pixel evidence.

013W uses it as an ablation test.

For each founding axis:

1. compile one explicit relaxation;
2. execute through the same FFmpeg witness raster;
3. hash the actual emitted frame bytes;
4. compare the complete frame graph with baseline;
5. require a real pixel consequence;
6. require repeated compilation/render to remain deterministic.

Therefore:

~~~
PARAMETER DIFFERENCE != CONSEQUENCE

but

DIFFERENT REAL FRAME GRAPH
  = visible executable consequence exists
~~~

Still:

~~~
PIXEL DIFFERENCE != CREATIVE VALUE
~~~

The human decides whether the consequence is useful.

## Graduation aperture

013W succeeds when:

1. zero axes preserve the exact source PerformanceProgram;
2. axis order is canonical;
3. unsupported or duplicate axes refuse;
4. coordinate relaxation produces deterministic changed real pixels;
5. experienced-time relaxation produces deterministic changed real pixels;
6. history-decay relaxation produces deterministic changed real pixels;
7. the three founding single-axis outputs are pixel-distinct from each other;
8. repeated compilation/render of one spec reproduces the same program and frame graph;
9. the source performance and source program remain unchanged.

Then the compiler is real.

The next move is not "more weird."

It is to add one new reality assumption at a time and require each to survive the same causal proof.
