# NEXTGEN-TOASTER-009 — PERFORMED TOPOLOGY

Status: experimental descendant of NEXTGEN-TOASTER-008 WATCH × PLAY × TRACE.

## Question

Can one real-time gesture against the admitted song become, at once:

1. witnessed human motion;
2. ordinary Franken placement animation;
3. topology-paint proposal material;

without collapsing witness, proposal, and freeze authority?

009 answers with one bounded path:

```text
hold Video Digestion lane
        +
move pointer through current live proposal scene
        ↓
audio-clock spatial samples
        ↓
sealed ONE PASS witness
      /                 \
     v                   v
placement keyframes    PerformanceTrace
existing renderer      topology stroke proposal
grammar                     +
                           syzygy
      \                 /
       \               /
           RECOMPOSE
               ↓
             REVIEW
               ↓
             FREEZE
```

## Performance surface

The current WATCH preview becomes a physical performance surface during ONE PASS.

While a material lane is held:

- pointer motion is read only when it is inside the currently active ARRIVE / CROSS / ASSEMBLE preview viewport;
- sample time comes from the same admitted audio clock as the take;
- x/y are normalized into the current scene;
- samples outside the active scene are ignored;
- keyboard-held lanes and pointer-held lanes use the same sampling path;
- multiple simultaneously held lanes may inherit the same witnessed pointer path.

The UI may show that a path is being witnessed. That indicator is observational.

## Spatial witness

The ONE PASS receipt remains `witness-only` and now carries:

```text
spatialSamples[]
spatialSampleCount
```

Each sample names:

- gesture sequence;
- lane;
- material identity;
- audio-clock frame;
- normalized x/y;
- bounded scale;
- bounded rotation.

The stream is capped at 384 samples.

Multiple pointer reports inside the same performance frame coalesce to the last observed sample for that lane/gesture/frame.

```text
POINTER EVENT != SAMPLE COUNT
SAMPLE != KEYFRAME AUTHORITY
```

## Animation crossing

ONE PASS already derives lawful scene-bounded placements from raw down/up events.

009 uses only spatial samples belonging to that exact gesture and placement span to derive transform keyframes.

The existing 006 contract remains authoritative:

- x / y / scale / rotation;
- no more than four transform keyframes per placement;
- keyframes must remain inside the placement;
- scene boundary splitting still happens first;
- source-duration splitting still happens first;
- both existing projectors consume the ordinary frozen keyframe grammar.

Dense performance motion is therefore deterministically reduced into at most four representative spatial states per lawful placement.

No second animation representation is introduced.

## Topology stroke crossing

PerformanceTrace still emits a held-material stamp when there is no witnessed spatial path.

When a lawful placement has at least two witnessed spatial samples, TRACE instead emits:

```text
brush.kind = performed-spatial-stroke
brush.path[]
brush.pathLength
```

The path is bounded to at most sixteen proposal points.

This is explicitly topology-paint proposal material. It is not renderer execution.

```text
PERFORMED PATH != TOPOLOGY AUTHORITY
TRACE != FREEZE
```

## What one gesture now means

A single gesture can lawfully have three descendants:

```text
human gesture
    |
    +-- raw spatial witness
    |
    +-- placement animation proposal
    |
    '-- topology stroke proposal
```

The descendants share ancestry but remain different objects.

```text
WITNESS != ANIMATION
ANIMATION != PAINT
PAINT != SOURCE
SAME GESTURE != SAME AUTHORITY
```

## Video compost consequence

A finished clip may already have been digested into:

- texture;
- topology mask;
- motion mask;
- other bounded descendants.

009 means a human can now physically perform one of those descendants through the song.

The placed descendant may appear visibly while its witnessed path becomes paint proposal material.

This enables the first honest version of:

> move the ghost, and its ruins scratch the room.

The source clip may survive as appearance, ancestry, motion, residue, or some combination of those without those roles collapsing into one thing.

## Current syzygy

TRACE still carries the explicit relation:

```text
performed hold duration
        ↓
     linear map
        ↓
topology brush amount
```

009 adds spatial path evidence but does not silently invent another relation from it.

A later slice may deliberately bind:

- path length → persistence;
- velocity → scratch density;
- acceleration → displacement;
- scale → brush width;
- rotation → grain orientation;
- source kinship → cross-descendant behavior.

Each must be explicit and reviewable.
