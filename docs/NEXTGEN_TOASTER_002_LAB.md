# NEXTGEN TOASTER 002 — Human-Visible Lab

Status: experimental descendant of the green NEXTGEN-TOASTER-001 exact-SHA carrier.

## Purpose

NEXTGEN-TOASTER-001 proved that the selected organs can survive one composed proof
pipeline at exact commit identities. 002 puts that lineage in front of the human
without claiming those source trees have been merged.

The first visible path is intentionally small:

```text
HEAR
  current song admission / Listener surface
    ↓
DREAM
  current Six-Up candidate ecology
    ↓
COMPOSE
  FRANKEN COMPOSER proposal → explicit freeze
    ↓
RENDER
  ordinary Haunted Toaster render → receipt
```

The rail observes the existing product state. It does not create a parallel acceptance
system.

## What is real in this slice

- `NEXTGEN LAB` is a visible door in the Electron renderer.
- HEAR completes only when the ordinary song facts are actually present.
- DREAM completes only when the ordinary beta Six-Up grid has candidates.
- COMPOSE completes only when Franken Composer exposes a frozen plan hash.
- RENDER completes only when the ordinary render result witness is visible.
- Clicking COMPOSE opens the existing Franken Composer bench through a bounded DOM event.
- The exact NEXTGEN-TOASTER-001 carrier profile is read through one read-only IPC method.
- The organ panel shows the exact pinned branch + SHA identities and authority classes.

## What this slice does not claim

- no donor Git histories are merged;
- no profile pin gains runtime or acceptance authority;
- no candidate is automatically KEEP'd;
- no Franken proposal is automatically frozen;
- no render is automatically started;
- no external media is uploaded;
- no CI proof receipt is presented as a local runtime receipt;
- no product graduation or release.

## UI law

```text
RAIL != AUTHORITY
OBSERVED STATE != NEW STATE
PROFILE != EXECUTION
DOOR != CROSSING
FREEZE REMAINS EXPLICIT
RENDER REMAINS EXPLICIT
```

## Witness

The UI witness must prove the path against the existing beta Home and Franken fixtures:

1. beta Home reaches HEAR + DREAM;
2. COMPOSE is the next live door;
3. the exact carrier profile exposes nine pinned organs;
4. opening COMPOSE reaches the actual Franken bench;
5. proposal remains separate from freeze;
6. only explicit freeze marks COMPOSE complete;
7. RENDER becomes the next live door;
8. legacy alpha visual baselines remain unchanged by hiding the additive NextGen
   furniture in those ancestral screenshot comparisons.

That is enough for 002. The next descendant can start composing additional proven organs
inside this visible shell rather than adding more navigation.
