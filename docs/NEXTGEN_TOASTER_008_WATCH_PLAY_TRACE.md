## Three different kinds of truth

### WATCH

WATCH answers: **what am I currently seeing and hearing?**

It may expose admitted local preview URLs, seek admitted media, follow the real song clock, scrub, and zoom.

WATCH is observational.

```text
PREVIEW URL != PROPOSAL DATA
PLAYHEAD != RENDER AUTHORITY
SONG CLOCK != PLACEMENT AUTHORITY
```

### PLAY

PLAY answers: **what did the human actually do while the song moved?**

ONE PASS seals raw down/up timing, derived lawful placements, and a deterministic performance fingerprint.

PLAY is witnessed performance.

```text
PERFORMANCE != OPTIMIZATION
MISS != ERROR
EVENT RECEIPT != RENDER AUTHORITY
PERFORMANCE PLACEMENT != FREEZE
```

### TRACE

TRACE answers: **what creative relations can lawfully be proposed from that witnessed performance?**

TRACE does not alter the receipt.

The first v0 compiler derives:

- one bounded topology paint proposal from each performed placement;
- one explicit syzygy proposal binding hold duration to paint amount;
- a deterministic trace hash;
- no preview URLs;
- no renderer instructions;
- no automatic KEEP or FREEZE.

Current ONE PASS has lane presses and held placements but no continuous pointer trajectory. Therefore v0 honestly emits held-material paint **stamps**, not invented brush paths.

When performed transform trajectories exist, TRACE may grow from stamps into strokes without changing the custody law.

Core law:

```text
WATCH != PLAY
PLAY != TRACE
TRACE != FREEZE
SIGNAL != MATERIAL
PAINT != SOURCE
SYZYGY != OBJECT
RELATION != AUTHORITY
```

## Why this is the seam for video compost

A finished video can already enter Video Digestion and become multiple addressable descendants.

ONE PASS lets a human perform those descendants against the song.

TRACE lets that same performance become proposal material for topology painting and relation-building.

So a finished video can now move toward:

```text
finished clip
   -> digestion descendants
   -> performed placement
   -> topology residue
   -> relation
   -> reviewed composition
```

The clip no longer has to survive literally to remain causally present.

## First strange extension

The first strong next experiment is **kinship syzygy**.

If multiple placed descendants share one admitted source lineage, their relations may remain genealogically explicit:

```text
source A
  |- A:ghost
  |- A:motion
  |- A:edge
  '- A:palette

A:ghost placement
     -> locates A:motion paint

A:ghost hold duration
     -> controls A:edge scratch intensity

A:palette
     -> stains residue left by A:motion
```

That requires carrying source-lineage identity into the performance lane receipt. V0 does not invent it from material names.

## Nonclaims

- topology paint is proposal grammar, not yet renderer execution;
- syzygy is proposal grammar, not yet renderer execution;
- WATCH preview is not final pixels;
- TRACE does not mutate the sealed ONE PASS witness;
- no automatic acceptance;
- no merge to main;
- no claim of full-song duration beyond the current carrier.

## Next proof

A useful human proof is:

1. load one real song and one admitted video;
2. WATCH the real admitted proposal media;
3. perform the six digestion descendants in ONE PASS;
4. seal the take;
5. derive PerformanceTraceV0;
6. show the proposed topology stamps beside the ordinary placements;
7. accept/reject/edit them separately;
8. RECOMPOSE;

The artistic question is whether the performed video bits feel like **material becoming soil**, rather than clips receiving effects.
