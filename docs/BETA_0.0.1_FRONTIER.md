## Anti-loss procedure

For every future touch:

1. read this registry;
2. inspect current code/tests/receipts before issue prose;
3. move each seam to the correct state;
4. when work lands, record the exact PR/commit/test evidence and remove any obsolete “not built” wording;
5. never promote `open issue`, `spreadsheet row`, resemblance, or narrative elegance into implementation truth;
6. mirror this registry into sheets only for sorting/filtering; the repository copy remains the durable source.

## Spreadsheet mirror contract

A spreadsheet mirror, when generated, should contain at minimum:

`state | issue | title | current_truth | remaining_delta | beta_0_0_0_blocker | priority | evidence | source`

It is an index. If it disappears, the project loses convenience, not truth.
