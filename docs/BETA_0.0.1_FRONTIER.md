## Anti-loss procedure

1. Read this registry.
2. Inspect current code/tests/receipts before issue prose.
3. Read the issue's exact acceptance cells and later comments before changing disposition.
4. Move each seam to the correct state; do not infer implementation from resemblance.
5. When work lands, record exact PR/commit/test/human evidence and delete obsolete “not built” wording.
6. Never promote `open issue`, `spreadsheet row`, resemblance, metric, or narrative elegance into implementation truth.
7. Mirror this registry into sheets only for sorting/filtering. The repository copy remains durable source.

## Spreadsheet mirror contract

A spreadsheet mirror should contain at minimum:

`state | issue | title | current_truth | remaining_delta | beta_0_0_0_blocker | priority | evidence | source`

It is an index. If it disappears, the project loses convenience, not truth.
