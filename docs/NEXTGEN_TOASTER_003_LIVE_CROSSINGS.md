# NEXTGEN TOASTER 003 — Live Organ Crossings

Status: experimental descendant of the green NEXTGEN-TOASTER-002 human-visible lab.

## Question

Can two proven donor organs stop being profile entries and begin changing the actual
Franken composition path without gaining authority they never had?

003 crosses:

- Listening Eye → visible Franken proposal pressure;
- Video Digestion Six-Up → six addressable derived-video materials in the Franken reservoir.

## Listening Eye crossing

The transplanted Listening Eye code is pinned back to the repaired donor:

- branch: `fix/listening-eye-family-evidence-001`
- SHA: `8d83d678221e28e7f81bb619fd9834fe28147f97`

The current inspected song is converted to the existing generation analysis contract.
Listening Eye produces six art-direction lenses. A deterministic pressure adapter then
suggests only controls already owned by Franken Composer:

- moving-take scene;
- ARRIVE → CROSS transition;
- CROSS → ASSEMBLE transition;
- variation.

It does not choose Playdeck cards, KEEP a candidate, freeze, render, or publish.

Loading the crossing updates the visible Franken controls. The human may change any of
them before RECOMPOSE. Those explicit edits override the pressure.

```text
LISTENING EYE
     |
     | influence-only
     v
visible Franken defaults
     |
     | human may edit
     v
RECOMPOSE
     |
     | human explicitly FREEZE
     v
frozen plan
```

## Video Digestion crossing

The transplanted Video Digestion Six-Up code is pinned back to:

- branch: `fix/video-digestion-vout-contract-001`
- SHA: `fce507efbe2381fcae4189a0f6b3689e0bf5c880`

When the current Toaster has both:

1. an admitted video source, and
2. a current candidate timeline,

the exact same source is digested into six proposal-only descendants:

- texture-loop
- texture-release
- topology-loop
- topology-stretch
- motion-release
- motion-stretch

All six become distinct addressable video materials in the Franken proposal and frozen
composition. Each carries its exact family hash, plan hash, operator, sampling policy,
projection class, and source digest.

The six materials are a **reservoir** in 003. They are intentionally not placed on a
scene track yet.

That distinction is important:

```text
MATERIAL IN PLAN != MATERIAL USED ON TIMELINE
DERIVATION RECEIPT != RENDERED PIXELS
RESERVOIR != PLACEMENT AUTHORITY
```

A future slice may add explicit human placement and projector support. 003 does not
counterfeit that work.

## Staleness / custody

The renderer receives only a public crossing view. Private source plans and paths stay
on the privileged side.

When Franken composes or freezes with live organs enabled, the main process recomputes
the crossing from current Toaster state. The reviewed crossing identity must match.
Changing the song, candidate timeline, admitted video, seed, or other identity-bearing
state makes an old crossing stale and the operation refuses.

## Authority laws

```text
LISTENING != PLACEMENT AUTHORITY
PRESSURE != EDIT
EDIT != FREEZE
VIDEO DIGESTION != TIMELINE PLACEMENT
RESERVOIR != RENDER
PUBLIC VIEW != PRIVATE SOURCE PLAN
STALE CROSSING != ACCEPTED CROSSING
```

## Graduation proof

003 is credible only if tests prove:

1. Listening Eye pressure is deterministic and influence-only.
2. The same admitted video yields six distinct reservoir identities.
3. The public renderer view contains no private digestion plans.
4. Franken refuses a stale crossing identity.
5. A reviewed crossing survives proposal → explicit freeze.
6. The frozen plan retains all six derivation receipts.
7. The live UI shows the pressure and six-up reservoir before FREEZE.
8. Human editor changes remain able to override pressure.
9. Existing non-NextGen Franken and renderer proofs remain green.
