> The Toaster remembers through six different apertures at once.

## Why this exists

The current Toaster already contains the safe memory organs:

- immutable successful-render archive;
- append-only Human Verdict receipts;
- deterministic Memory Projection;
- bounded MemoryCapsules;
- Influence Trace;
- witness disposition.

But the latest tested creative loop did not actually read that memory during ordinary candidate generation.

Historical PR #166 once proved a one-seat memory influence model. It remained unmerged, and PR #218 later rescued only the safe service foundation. MEMORY-001 reuses the surviving authority law but does **not** restore the old one-memory-seat anatomy.

Each candidate hears a different class of remembered pressure.

        ↓

## Pressure law

Each aperture receives one deterministic bounded influence proposal.

The pressure may:

- apply;
- already be satisfied;
- be refused because the axis is locked;
- be refused because the target is not lawful.

```text
REMEMBERED != OBEYED
PRESSURE != RESULT
PAST SUCCESS != COMMAND
PAST FAILURE != PROHIBITION
LOCK > MEMORY
CONSTRAINT > MEMORY
```

## Authority boundary

Memory changes proposal/search state only.

It does not become:

- VisualScore authority;
- ResolvedTimeline authority;
- topology-event authority;
- renderer state;
- a hidden timeline;
- ancestry merely because it was remembered.

The renderer never receives ambient MemoryContext or MemoryPrism state.

When a memory-influenced candidate is rendered, only compact candidate-genealogy evidence crosses the receipt boundary:

- prism identity;
- capsule identity;
- seat/aperture;
- bounded influence target;
- evidence refs;
- application/refusal result.

## Durable loop

Successful canonical renders are archived **after** render acceptance.

Archive failure cannot revoke an already successful render.

```text
GENERATE
  ↓
KEEP
  ↓
RENDER SUCCESS
  ↓
IMMUTABLE ARCHIVE
  ↓
NEXT GENERATION PROJECTION
  ↓
SIX-UP PRISM
```

That closes the first real developmental-memory loop.

## Proof obligations

Machine proof must establish:

1. no archived render -> no prism -> exact ordinary six-up;
2. one accepted archived score/receipt reconstructs all six memory feature classes;
3. six prism seats are fixed, distinct, and deterministic;
4. each seat can lawfully alter only its assigned score axis;
5. all six applications remain attributable to archive/song evidence;
6. locks override memory;
7. the same prism + source + seed replays exact score/timeline/family identity;
8. Influence Trace points each pressure at its actual candidate seat;
9. successful render archival happens only after canonical render success;
10. archive failure cannot revoke render success;
11. renderer implementation contains no ambient memory decision state;
12. existing no-memory and historical memory-foundation tests remain green.
