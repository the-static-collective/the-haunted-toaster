# FRANKEN-COMPOSER-001 Reconciliation Witness

Status: implementation witness; package handoff remains gated by ready-for-review CI.

## Scope

FRANKEN-COMPOSER-001 proves a bounded deterministic composition bench in Haunted Toaster. Playdeck contributes proposal material and world-rule context, Haunted Blender contributes one explicitly filmmaker-accepted private-preview moving take, and Haunted Toaster owns proposal review, freeze, canonical plan identity, and receipts. HyperFrames and Remotion are projections of the frozen plan, not composition authorities.

No donor repository was mutated by this implementation.

## Authority and refusal checks

The implementation refuses rather than silently coercing:

- stale Playdeck source bytes;
- missing or remote logical-asset bindings;
- malformed or stale Blender acceptance/admission/video lineage;
- source-window overflow;
- unsupported renderer semantics;
- invalid scene/transition geometry;
- hidden entropy or post-freeze mutation;
- implicit publication permission;
- output overwrite of immutable witness bundles.

Proposal state remains proposal-only until the explicit freeze boundary. Renderer receipts cannot rewrite the composition receipt.

## Known bounded limitation

The generated HyperFrames HTML currently references the pinned GSAP runtime from jsDelivr. No user media is uploaded and no hosted HyperFrames render was used, but this means the HTML witness should not be described as fully network-independent/self-contained. HyperFrames lint/validate/inspect were executed against the generated project and passed.

## Nonclaims

This witness does not claim:

- hosted HyperFrames execution;
- pixel-identical or byte-identical renderer output;
- provider execution beyond the evidence encoded in donor receipts;
- publication/distribution rights from Blender private-preview acceptance;
- automatic KEEP;
- release/tag/main promotion;
- merge authorization.
