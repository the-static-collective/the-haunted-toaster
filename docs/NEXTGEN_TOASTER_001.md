# NEXTGEN TOASTER 001 — Composed Organ Carrier

Status: experimental integration carrier.

## Goal

Turn the Haunted Toaster branch ecology into one testable next-generation instrument
without pretending every branch should be merged into one Git history.

The carrier is assembled as a sequence of bounded organs:

Each organ is pinned to an exact repository, branch, and commit SHA.

## Why this is different from a mega-merge

The organs have different authority classes.

- Listener × Look-Twice is diagnostic-only.
- Listening Eye is influence-only.
- Video Digestion is proposal-only.
- Memory Prism applies bounded proposal pressure.
- Franken Composer owns the frozen experimental composition plan.
- Blender contributes bounded material and proposal surfaces.
- Playdeck contributes continuation and renderer proposal surfaces.
- Batch Console is transport around existing KEEP/render gates.
- FrankenTester is diagnostic evidence.

The carrier therefore composes proofs and interfaces before source histories.

## Runtime gate

The workflow at .github/workflows/nextgen-toaster-001.yml checks out every selected
organ at its exact pinned SHA and runs that organ's focused proof in isolation.

Only after all jobs pass does the seal job create:

    static-collective/nextgen-toaster-proof-receipt/v0

The receipt binds:

- the current NextGen kernel SHA;
- every exact organ pin;
- one named runtime proof per organ;
- the NextGen profile;
- a deterministic receipt hash.

A green receipt means the selected organs independently passed their declared proof
at the pinned commits. It does not yet mean the combined UI is production-ready.

## Product direction

The intended next-generation Toaster loop is:

    hear more carefully
      -> orient visually
      -> multiply cheap material
      -> remember accepted history
      -> compose renderer-neutral structure
      -> use Blender for cinematic material
      -> use Playdeck for staged possibility/continuation
      -> transport an album through Batch
      -> leave receipts everywhere

The design target is not a conventional NLE.

It is a deterministic creative instrument where complexity comes from relations among
addressable materials, not from generating every frame from scratch.

## Graduation gate

NEXTGEN TOASTER 001 remains experimental until there is a human-visible integrated
witness that proves the selected organs can inhabit one usable Toaster surface.

Runtime proof is necessary, but:

    RUNTIME PASS != PRODUCT GRADUATION
